high Usability
'Default – Set up your scale' and 'Link Test' appear to be placeholder/test content visible to real users. 'Default' is an internal label that should never be user-facing, and 'Link Test' is clearly a developer test item.
Fix: Remove or replace test content before any user-facing build. Content titles should be descriptive and production-ready (e.g., 'Set Up Your Scale').
high Consistency
The two content cards use completely different layouts: the first is a large vertical card with a thumbnail on top and text below; the second is a compact horizontal row with a small square thumbnail on the left. They represent the same content type (Video & PDF section) but look like they belong to different apps.
Fix: Standardize all content cards in this section to use the same layout pattern — either both vertical or both horizontal — so users can visually scan consistently.
medium Accessibility
The email verification banner uses a light pink background with red/dark-red text. While likely readable, the contrast between the pink background and the red icon/border may be insufficient for users with red-green color deficiency, and the banner relies heavily on color (red) to signal urgency.
Fix: Add a text label like 'Action required' or a non-color indicator (e.g., exclamation icon) so urgency is communicated without relying solely on red color.
medium Visual design
The 'Week 2' badge button in the Video & PDF section header is dark navy, visually identical in style to the active tab ('This week'). It's unclear whether 'Week 2' is a navigation control, a label, or a filter — its affordance is ambiguous.
Fix: If 'Week 2' is just a label indicating current content, use a lighter or outlined pill style. If it's interactive, label it more clearly (e.g., 'Change week').
medium Usability
The 'CATCH UP' section is barely visible at the bottom of the screen — only the heading peeks out — with no visual cue that it's scrollable. A user could easily miss that more content exists below.
Fix: Increase the peek height of the next section or add a subtle scroll indicator/fade to signal that the page continues below the fold.
low Consistency
The info icon (ⓘ) next to the 'Learn' heading is visually inconsistent with other header controls (chat and bell icons). The ⓘ uses a thin circle outline while the other icons are filled/stroked differently.
Fix: Align the ⓘ icon style (weight, fill) with the other header icons for a cohesive look.
