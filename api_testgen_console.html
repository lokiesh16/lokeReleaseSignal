UI Tests

          
Record by hand or let AI explore, replay to verify, then generate Playwright tests.

        

        
      

      


        

          How it works & tips
          
    
            
  • Record: launch your app (bar above), press ⏺ Start recording, then use the app normally. Clicks, typing, dropdowns and Enter become steps.
    • 
            
  • In the browser, a toolbar appears: 🎯 Pick selects an element without clicking it so you can assert its text/value/link, hover, wait for it, scroll to it or clear it. ⚓ Anchor finds controls by their label so changing values (dates, chosen options) don't break the test.
    • 
            
  • Two portals? Launch both, record in Both A + B: steps are tagged A/B and replay in two separate windows (separate logins).
    • 
            
  • Edit steps: the ⋯ menu on a step checks or edits its locator and inserts a wait / go-to / test-case split. ▶ replays everything up to that step.
    • 
            
  • Verify: Replay all runs the whole flow in fresh windows (tick Report for an HTML report with screenshots).
    • 
            
  • Generate: name the test and click Generate for a page file + test class. Passwords are kept in owner-only local files, never in the generated code.
    •
